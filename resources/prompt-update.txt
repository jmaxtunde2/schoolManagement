# 4. MODÈLE ÉCONOMIQUE

## Première année

Le coût total de la première année est :

**150 000 FCFA**

Ce montant couvre :

- activation de CoriSchool
- première année de licence
- configuration initiale
- onboarding
- configuration de l'environnement
- accompagnement initial
- import initial selon les fonctionnalités prévues
- création/configuration du compte administrateur.

### RÈGLE CRITIQUE

**150 000 FCFA est le prix TOTAL de la première année.**

Il ne faut surtout pas calculer :

```text
150 000 + 70 000
```

pour la première année.

La logique est :

```text
Année 1 = 150 000 FCFA
Année 2 = 70 000 FCFA
Année 3 = 70 000 FCFA
Année 4 = 70 000 FCFA
```

Exemple :

```text
2026-2027 → Initial → 150 000 FCFA
2027-2028 → Renewal → 70 000 FCFA
2028-2029 → Renewal → 70 000 FCFA
2029-2030 → Renewal → 70 000 FCFA
```

Le système doit donc distinguer explicitement :

- `initial`
- `renewal`

Une licence initiale représente :

**Activation + première année de licence**

et non simplement des frais d'installation.

# 11. APPROBATION ≠ ACTIVATION

C'est une règle métier importante.

Lorsqu'une démonstration est terminée :

```text
demo_done
    ↓
approved
```

Mais :

**approved ≠ active**

L'école n'est pas encore activée.

Le processus devient :

```text
Demo effectuée
      ↓
École approuvée
      ↓
Paiement initial demandé
      ↓
150 000 FCFA confirmé
      ↓
École activée
      ↓
Licence initiale créée/activée
      ↓
Compte administrateur créé/activé
      ↓
Onboarding
```

# 15. ACADEMIC YEAR ≠ LICENSE

Ne jamais fusionner ces deux concepts.

Une école peut avoir plusieurs années :

```text
School
 ├── AcademicYear 2026-2027
 ├── AcademicYear 2027-2028
 └── AcademicYear 2028-2029
```

Et des licences correspondantes :

```text
School
 ├── License 2026-2027 / initial / 150000
 ├── License 2027-2028 / renewal / 70000
 └── License 2028-2029 / renewal / 70000
```

Une licence donne le droit d'utiliser CoriSchool pour une période donnée.

# 19. TRANSITION ENTRE ANNÉES

Ne jamais simplement modifier l'ancien `class_id` d'un étudiant.

Il faut conserver l'historique académique.

Le modèle cible est idéalement :

```text
Student
   ↓
Enrollment
   ↓
School
AcademicYear
Class
```

Exemple :

```text
Jean
2026-2027 → 6e A
2027-2028 → 5e B
2028-2029 → 4e A
```

Les anciennes affectations restent intactes.

